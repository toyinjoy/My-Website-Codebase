# joyomole.com

Personal website of Oluwatoyin Joy Omole, BI consultant for small businesses.

- `index.html` is the whole site: content, styles and layout in one file.
- `joy-headshot.jpg` is the About photo.
- `CNAME` tells GitHub Pages to serve the site at joyomole.com.

To change text, edit `index.html` and commit; GitHub Pages republishes within a minute or two.
